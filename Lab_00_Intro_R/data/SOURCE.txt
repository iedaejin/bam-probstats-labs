mtcars.csv
  Source: R package 'datasets' (R Core Team), object 'mtcars': road tests of 32 cars from the 1974 Motor Trend US magazine.
  Reference: Henderson and Velleman (1981) Building multiple regression models interactively. Biometrics 37, 391-411.
  Columns: car (model name, from the row names), mpg, cyl, disp, hp, drat, wt, qsec, vs, am, gear, carb. Values unchanged;
  written with write.csv(data.frame(car = rownames(mtcars), mtcars, row.names = NULL), row.names = FALSE).
